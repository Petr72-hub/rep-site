0. Домен и публикация

   Сайт публикуется на GitHub Pages по адресу https://catalisator.ru/
   Домен зафиксирован в файле CNAME в корне репозитория — GitHub Pages
   читает его при каждой публикации. Этот же адрес прописан в og:url,
   og:image и canonical в index.html.

1. Артефакты в слове «понимания» (первый экран)

   Причина не в CSS. В шрифте Montserrat стойки и диагонали кириллических
   букв (п, м, и, я) — отдельные пересекающиеся контуры. При обычной
   заливке швы не видны, а -webkit-text-stroke обводит каждый подконтур,
   поэтому внутри букв появлялись «стрелки».

   Решение (styles.css, блок V5-1): paint-order:stroke fill — обводка
   рисуется первой, поверх неё непрозрачная заливка цветом фона. Она
   закрывает внутренние швы и внутреннюю половину обводки; остаётся
   ровный внешний контур. Для старых браузеров есть @supports-запасной
   вариант.

2. Мобильная оптимизация (styles.css, блок V5-2)

   — убран горизонтальный сдвиг страницы (overflow-x на html + body);
   — учтены «чёлка» и жесты iPhone: viewport-fit=cover + env(safe-area-*);
   — scroll-padding-top: якорь больше не прячется под фиксированной шапкой;
   — слово «понимания» подгоняется по ширине экрана и не обрезается;
   — площадь нажатия ≥44 px, убрано «залипание» :hover на тач-экранах;
   — видимый фокус с клавиатуры;
   — лента материалов: скролл-снап, скрытая полоса прокрутки, стрелки
     отключаются на краях;
   — отдельные брейкпоинты на 400 px и на альбомную ориентацию;
   — на телефонах отключены тяжёлые декоративные элементы (орбы, формулы).

3. Разметка и скрипты

   — index.html: иконка сайта, Open Graph (превью ссылки в мессенджерах),
     микроразметка schema.org, preload главного фото, width/height +
     loading="lazy" у картинок (страница перестала «прыгать» при загрузке);

   — data.json заполнен реальными ссылками.
